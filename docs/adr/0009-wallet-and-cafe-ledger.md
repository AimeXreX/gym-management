# ADR 0009 — کیف پول و کافه با دفترکل تغییرناپذیر

## وضعیت

پذیرفته‌شده — 2026-08-01

## زمینه

اعضا باید بتوانند اعتبار نگه دارند و در کافه خرج کنند. نگهداری یک balance قابل‌ویرایش، audit و بازیابی مالی را شکننده می‌کند.

## تصمیم

- هر عضو در هر Gym یک Wallet دارد و مانده cache‌شده آن فقط داخل transaction و هم‌زمان با درج Wallet Transaction تغییر می‌کند.
- تراکنش دفترکل حذف یا ویرایش نمی‌شود. اصلاح با reversal دارای reference یکتا انجام می‌شود.
- شارژ نسخه اول توسط کاربر مجاز ثبت می‌شود. اتصال PSP بعدی یک credit را فقط پس از callback امضاشده و idempotent ثبت خواهد کرد.
- سفارش کافه snapshot نام و قیمت اقلام را نگه می‌دارد. پرداخت کیف پول، کاهش موجودی و تکمیل سفارش در یک transaction و با row lock انجام می‌شود.
- موجودی منفی، کالا یا عضو cross-tenant و replay reference رد می‌شود.

## خارج از دامنه فعلی

درگاه بانکی، مالیات رسمی، حسابداری دوبل، برگشت خودکار PSP و سفارش delivery نیازمند ADR و provider مشخص‌اند.
